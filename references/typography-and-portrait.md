# 人物与字体系统

## 人物商业化处理

先保身份，再做风格化；不得为“更上镜”改变脸型、五官比例、年龄、肤色、发型或眼镜。

- 人物必须有清晰眼神光、自然皮肤纹理和与场景一致的主光、轮廓光、地面反射。
- 清理原图中无关的讲台、麦克风、路人、品牌字样与杂乱背景；保留真实衣物质感。
- 抠图边缘用与场景相连的 2–6px 亮边或柔影，不可形成硬白边。贴纸风才可用浅黄/白色描边。
- 单独检查：眼镜镜片反光、耳朵边缘、发际线、肩部透视、双手和手指。任一项异常即重做。
- 根据内容指定动作，不要总用“指向镜头”：解释用指向标题，测评用推卡片，效率用展示仪表，推荐用托物或点赞，观点用正面对视。
- 如果已有透明人物 PNG，优先做真实前景遮挡：人物边缘可以压住标题或证据数字的 5%–20%，但不能遮住眼睛、嘴巴、产品名或关键数字。没有透明人物时，生成无字主视觉阶段就要预留人物与标题安全区，不要在后期做粗糙硬抠图。
- 默认不把人物做成“真实全身 + 换背景”。在内容需要概念表达时，优先保持真实脸部和表情，把身体转化成纸雕、拼贴、软胶玩具、木偶、发条装置或超现实道具；身体材质必须与场景同属一个视觉世界。短视频爆款模式下，如果人物还是写实半身照或讲师站姿，直接判失败并重做。

## 字体角色

普通后期叠字只使用随 Skill 附带且许可证已保存的字体。爆款大头封面默认不走本地叠字脚本，关键中文必须使用参考图同款的生成式 3D 招牌字。当前普通封面家族默认收敛为：

- 主标题：`YouSheBiaoTiHei.ttf`（优设标题黑），窄斜、粗壮、带尖角，承担唯一的主视觉锤。
- 信息黑体：`SourceHanSansSC-Heavy.otf`（思源黑体 SC Heavy），用于副标题、数字和信息卡，提供稳定、清晰的重磅对比。
- 辅助信息：`SmileySans-Oblique.ttf`（得意黑），只用于普通商单 kicker 与极短小标签，避免与主标题抢层级；爆款大头封面不要做左上角小胶囊 kicker。

不要在同一张封面里混用漫画体、圆体和装饰性黄油字体作为主标题；换风格时优先改变构图、色彩和字效，而不是更换字族。

### 字体的层级和材质

- 普通商单主标题是单一视觉锤：可用白→场景强调色的垂直渐变，配低调深色描边或柔影；不要同时上白描边、黑描边、贴纸边和投影。
- 普通商单副标题使用信息黑体，字号约为主标题的 18%–30%，可增加 4–14px 字间距，承担解释，不抢人物表情。
- 普通商单 kicker 使用得意黑或小型信息黑体，限定 2–8 字；允许放在色块、票据或小旗帜上。爆款大头封面禁止使用左上角小胶囊作为产品名或类别标签。
- 标题的尺度、倾斜、渐变和层级要与画面中的红色轨道、舞台灯、纸张折线、手势或道具产生关系；不得孤立地整齐压顶。

### 爆款大头招牌字标准

爆款大头封面的正确排版是图文一体生成出来的顶部招牌，不是后期脚本贴字。默认按已确认样张执行：

- 主标题占顶部 25%–35%，可略倾斜、略透视，允许压到安全区边缘但不能被平台裁切。
- 主标题是黄到橙的 3D 厚块渐变字，有明显挤压厚度、黑色内描边和黑色投影。
- 主标题外侧必须有粗白描边，再叠一层蓝色、橙色或白色发光外轮廓；边缘不能只有暗黄色光。
- 产品名或解释副标题用亮绿色粗斜 3D 字，紧贴主标题下方或嵌入标题组，尺寸约为主标题高度的 35%–55%。
- 英文产品名和中文主标题可以混排成两层，例如 `Codex解锁 / 不限时开工`、`GPU组队 / Mesh LM`、`AI画图表 / Flint`。
- 正式成品禁止出现浅黄平面大字、左上角小胶囊标签、细小青色副标题、孤立后贴投影字、脚本感 `blast` 字。

### 每张封面的字体决策表

先独立选择下面三项，再开始生成或叠字；不要把“字体风格”和“颜色效果”混为一项。

| 决策维度 | 可选方案 | 适用原则 |
| --- | --- | --- |
| 字体角色 | 超粗标题黑（优设标题黑） / 信息黑体（思源黑体 SC Heavy） / 个性短标签（得意黑） | 主标题只用一种；信息层和标签最多各加一种 |
| 颜色效果 | 纯白 / 纯黑 / 白到场景强调色的双色渐变 / 低调深色描边 | 深色背景优先纯白或浅色渐变；浅色背景优先纯黑或深色；描边只为分离背景，不能成为第二个标题 |
| 文字与人物关系 | 人物遮挡标题 / 文字压道具边缘 / 文字独占留白 / 上下夹住脸 / 标题穿插前中后景 | 每张只选一种主关系，并给人物的眼睛和嘴巴保留安全区 |

#### 构图到字体关系的默认映射

- 短视频爆款 / 大头角色：必须复刻样张的图文一体 3D 招牌字，不使用 `--treatment blast` 当正式输出。样张字体特征：极粗斜体中文，黄橙 3D 渐变，厚黑内描边，粗白外描边，蓝/橙/白色发光外轮廓，顶部倾斜压满 25%–35%，绿色产品副标题紧贴主标题。
- 深色渐变 / 强冲击：超粗标题黑，纯白或双色渐变；主标题放在人物背后，人物/道具遮住标题边缘。
- 纯色扁平 / 玩具剧场：超粗标题黑或信息黑体；高饱和强调色；标题与大前景道具发生遮挡。
- 产品主视觉：信息黑体做主标题；纯黑或纯白；标题压在产品边缘，不能覆盖关键 UI。
- 极简留白 / 人物侧置：信息黑体或中等字重标题黑；纯黑；字间距放宽，标题独占留白。
- 正面对视：超粗标题黑；纯白、纯黑或双色渐变；标题分上下两组夹住脸，避开五官。

| 角色 | `--style` | 适用 | 表现建议 |
| --- | --- | --- | --- |
| 综艺斜体 | `variety` | 强钩子、挑战、结果 | 黄白混排、厚黑描边 |
| 漫画标题 | `comic` | 反差、测评、惊喜 | 贴纸外轮廓、爆炸形或箭头 |
| 硬朗科技 | `tech` | AI、云、工具、效率 | 白字/青绿强调、信息卡 |
| 亲和圆润 | `round` | 推荐、经验、教程 | 浅黄、圆角横幅、低攻击性 |
| 编辑海报 | `editorial` | 商单、观点、数据洞察 | 小标题 + 大数字 + 规整网格 |

手写感只允许用于 2–6 字注释、箭头、圈点或“实测”等辅助信息，不得代替主标题。

## 标题版式

根据内容选择一种，而非默认居中压顶：

- `top`：强结论，顶部两行，最稳妥。
- `split`：对决、反差或数字，首行左锁、第二行右锁，形成节奏。
- `side`：人物或产品居一侧，另一侧大标题；适合更高级的商单和观点。
- `ribbon`：教程、清单、利益点；标题放深色圆角横幅，易读且可信。
- `poster`：大标题用双色渐变，配小 kicker，适合数据结论和行业观点。

每张只保留一个主标题锤、一个辅助信息层和最多三个装饰元素。大数字优先独立放大；不要把标题、副标题、标签全部做成相同描边字。

## 证据数字与爆款层次

`--metric` 是证据层，不是第二个标题。只放文案已有或用户明确给出的事实，例如节省倍数、工具数量、步骤数、时长、预算、版本号。推荐长度 1–4 个字，下面用 `--metric-label` 放短标签。

- 成本/效率：`--metric "18倍" --metric-label "出网成本"`，适合右侧或底部徽章。
- 清单/测评：`--metric "5款" --metric-label "实测工具"`，适合左侧徽章。
- 教程/路径：`--metric "3步" --metric-label "上手路径"`，适合底部徽章。

标题、人物、证据数字要形成前中后景：背景解释行业，标题制造停留，证据数字提供可信钩子，人物负责信任与动作引导。不要把四层都挤在顶部。
