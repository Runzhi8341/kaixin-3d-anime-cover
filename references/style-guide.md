# 开心科技封面风格指南

先匹配内容证据、人物角色和平台场景，再选择视觉系统。不要把爆款大字当成唯一答案。

## 标题公式

- 产品名 + 结果：`GPT-5 实测`
- 类别 + 强收益：`职场外挂`
- 数字 + 成本/效率：`流量费省18倍`
- 证据数字 + 口语结论：`18倍省钱`
- 结果 + 悬念：`100万 感谢`
- 对决/选择：`选谁？`
- 反常识：`P图真神`
- 教程承诺：`三分钟学会`

主标题不超过两行。英文产品名、关键数字和结果可以独立做第二层；不要虚构比较、价格或权威背书。

## 字体效果先于装饰

每张封面先确定标题的字族、颜色效果与空间关系，再决定是否添加箭头、图标或数字。字体不是最后贴上去的一行字，而是主视觉的一部分。

- 深色场景：白字或白→强调色渐变；让人物或前景道具遮住文字的局部边缘。
- 浅色留白：纯黑或深色信息黑体；放宽字间距，让文字占据留白而不是压住人物。
- 高饱和场景：使用与场景主色相关的渐变；副标题改用中性信息黑体，避免所有文字同时高饱和。
- 产品 / UI：标题贴近产品边缘或卡片边缘；不要遮挡产品的真实关键信息。

## 十种构图系统

| 系统 | 适用内容 | 人物与信息关系 | 字体/版式优先 |
| --- | --- | --- | --- |
| 爆款压顶 | 强收益、热点、反差 | 人物中下方指向核心物 | `variety` + `top` |
| 巨字拆分 | 选择、对决、概念 | 人物穿插于两组大字 | `comic` + `split` |
| 可信数据海报 | 商单、成本、行业洞察 | 人物为讲解者，数字为锤 | `editorial` + `poster` |
| 证据超级符号 | 有明确倍数、数量、步骤或时长 | 人物与徽章前后穿插，数字独立成记忆点 | `comic`/`editorial` + `poster` + `--metric` |
| 对比卡片 | 前后、贵/省、旧/新 | 人物推近结果卡 | `tech` + `split` |
| 产品主视觉 | 有 UI、设备或产品图 | 产品占 60%–70%，人物引导 | `tech` + `side` |
| 教程清单 | 上手、部署、路径 | 人物指向 3 条卖点 | `round` + `ribbon` |
| 工具工作流 | 多工具、效率方法 | 人物较小，流程卡为主 | `tech` + `ribbon` |
| 编辑留白 | 观点、品牌合作、人物访谈 | 人物侧置或小比例 | `editorial` + `side` |
| 贴纸拼贴 | 入门、组合、资源推荐 | 贴纸边缘人物 + 3–5 张卡片 | `comic` + `top` + `sticker` |
| 正面对视 | 争议、观点、人物故事 | 人脸居中，字上下夹住脸 | `variety` + `split` |
| 角色化隐喻 | 定位、选择、差异化、个人成长 | 真实脸部 + 非写实身体/道具，共同完成一个隐喻动作 | `editorial`/`variety` + `poster` |
| 玩具剧场 | 目标人群、筛选、服务对象 | 真实脸部附着于玩具/木偶身体，舞台中的群像承担人群隐喻 | `variety` + `poster` |
| 超现实路径 | 赛道、差异化、决策 | 角色沿一条与其他路径明显不同的路线运动 | `tech`/`editorial` + `side` 或 `poster` |

默认交付三版时，至少选三种不同系统；至少有一版使用角色化人物或超现实叙事。避免同时使用“未来城市 + 指向 + 顶部黄字”。

证据超级符号只在事实清楚时使用。没有来源的“第一”“最强”“省 90%”会削弱可信度，宁愿改成“实测”“避坑”“成本拆解”等口语钩子。

## 短视频爆款大头模式

当用户给出的参考是“大头人物 + 荒诞剧情 + 顶部超粗标题”的短视频封面时，优先执行 [爆款大头短视频封面标准](viral-avatar-thumbnail.md)。这类封面不追求克制高级感，追求停留率。

- 标题必须像图文一体 3D 招牌：黄橙主标题、绿色产品副标题、厚黑内描边、粗白外描边、蓝/白/橙外轮廓，顶部强占位。
- 禁止把普通后期字当爆款标题：浅黄平面大字、左上角小胶囊标签、细小青色副标题、脚本 `blast` 字都判失败。
- 人物必须像角色：大头、强表情、小身体、职业或剧情服装。
- 场景必须像一集故事：超市选 AI、月球插旗、云端飞行、竞技场判胜、办公室机器人打工。
- 每张至少两个 AI 工具符号或产品道具；没有授权 Logo 时使用抽象工具图标，避免伪造品牌细节。

## 场景、颜色与镜头

- 高能商业：蓝黄、橙黑、青绿；适合强结果和工具效率。
- 可信商单：墨蓝、暖白、青绿强调；适合成本、数据、云服务和 B2B。
- 亲和教程：米白、浅黄、绿色勾选；适合推荐和上手。
- 编辑观点：黑白、米灰、一个强强调色；适合大气留白和人物故事。

使用真实场景光源。写清左/右/上方主光、色温、环境反射与落地阴影，并确认同样作用在脸、眼镜、衣服和手上。

## 安全区

- 小红书 / 抖音 / 视频号：统一 3:4，推荐 1242×1656 或 1080×1440；标题和人脸离四边至少 5%，重点置于中央约 86% 宽、82% 高。
- 横版：1920×1080，人物置于一侧三分之一，标题占另一侧。

## 生成无字主视觉的硬约束

提示词必须含“不要任何文字、字母、数字、水印、Logo、平台 UI”。真实 Logo 与中文标题均由后期合成。不要脏乱机房、全息字、密集粒子、复制的人物、异常手指、塑料皮肤或未经授权的品牌标识。
